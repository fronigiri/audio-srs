# Audio SRS

This program uses a Spaced Repetation System (srs) focused strickly around audio memorization entirely made in Go.

# Commands

(for study page):

- H - restarts track
- M - pause/play track
- 1-4 - asigned to each rating

# Dependencies

- Go
- Library of music

# Quick Start

`go install https://github.com/fronigiri/audio-srs`
